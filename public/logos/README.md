# Logo đối tác / thương hiệu / khách hàng

Lưu file logo vào đúng thư mục này (`public/logos/`) với **đúng tên file** bên dưới.
Website sẽ tự động hiển thị. Nếu file chưa có, chỗ đó tạm hiện tên bằng chữ (fallback).

Khuyến nghị: **PNG nền trong suốt**, chiều cao ≥ 200px, đã crop sát logo.
(Nếu dùng SVG, đổi đuôi tên file trong `src/lib/data.ts` cho khớp.)
